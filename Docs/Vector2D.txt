#ifndef GAME_VECTOR2D_HPP
#define GAME_VECTOR2D_HPP


#include <cmath>
#include "Global.hpp"


/**
 * @file Vector2D.hpp
 * @brief A 2D vector, used both as a point or position and as a direction.
 *
 * @invariant Components are expected to be finite floating-point numbers.
 */
struct Vector2D {
    float x{0.0f};
    float y{0.0f};


    constexpr Vector2D() noexcept = default;
    constexpr Vector2D(float in_x, float in_y) noexcept : x(in_x), y(in_y) {}


    // --- Length ------------------------------------------------------------


    /// Squared length. For fast distance comparison.
    [[nodiscard]] constexpr float length_squared() const noexcept {
        return x * x + y * y;
    }


    /// Euclidean length.
    [[nodiscard]] float length() const noexcept {
        return std::sqrt(length_squared());
    }


    /**
     * @brief Returns a unit-length copy with the same direction.
     * @pre length() > EPSILON (the zero vector has no defined direction).
     * @post std::abs(result.length() - 1) < EPSILON.
     */
    [[nodiscard]] Vector2D normalized() const;


    /**
     * @brief Scales this vector in place to unit length.
     * @pre length() > EPSILON.
     */
    void normalize();


    /// Dot product.
    [[nodiscard]] constexpr float dot(const Vector2D& rhs) const noexcept {
        return x * rhs.x + y * rhs.y;
    }


    /// 2D scalar cross product.
    [[nodiscard]] constexpr float cross(const Vector2D& rhs) const noexcept {
        return x * rhs.y - y * rhs.x;
    }


    /// Approximate equality within a tolerance.
    [[nodiscard]] bool equals(const Vector2D& rhs, float tolerance = EPSILON) const noexcept;




    // --- Operators ---------------------------------------------------------


    [[nodiscard]] Vector2D operator+(const Vector2D& rhs) const noexcept;
    [[nodiscard]] Vector2D operator-(const Vector2D& rhs) const noexcept;
    [[nodiscard]] Vector2D operator*(float scalar) const noexcept;


    // @pre std::abs(scalar) > EPSILON.
    [[nodiscard]] Vector2D operator/(float scalar) const;  


    Vector2D& operator+=(const Vector2D& rhs) noexcept;
    Vector2D& operator-=(const Vector2D& rhs) noexcept;
    Vector2D& operator*=(float scalar) noexcept;


    // @pre std::abs(scalar) > EPSILON.
    Vector2D& operator/=(float scalar);
};

## Implementation Notes

### Precondition checks — why `length_squared() > EPSILON * EPSILON`

Calling `length()` (which calls `std::sqrt`) just to check if a vector is zero would waste a square root. Squaring both sides of `length() > EPSILON` gives an equivalent, **sqrt-free** guard:

```cpp
// Equivalent, but no sqrt:
assert(length_squared() > EPSILON * EPSILON);
```

### Reciprocal optimization

Wherever a scalar divisor is validated, the reciprocal is computed **once** and then used with multiplications — replacing two expensive `div` instructions with two cheap `mul` instructions:

```cpp
const float inv = 1.0f / scalar;  // one division
x *= inv;                          // two multiplications (cheaper)
y *= inv;
```

This applies to `normalized()`, `normalize()`, `operator/`, and `operator/=`.

### Assert discipline

| Method | Condition asserted |
|---|---|
| `normalized()` | `length_squared() > EPSILON * EPSILON` |
| `normalize()` | `length_squared() > EPSILON * EPSILON` |
| `operator/` | `std::fabs(scalar) > EPSILON` |
| `operator/=` | `std::fabs(scalar) > EPSILON` |

All asserts include a **string message** for instant diagnosis. In release builds (`-DNDEBUG`), `assert` expands to nothing — **zero runtime cost in production**.

## Test Design Notes

### 3-4-5 Triangle for `length()`
Integer Pythagorean triples give **exact** floating-point results (`sqrt(25.0f) = 5.0f`), eliminating accumulated rounding error as a variable. The 5-12-13 triple is used a second time in `normalize()` for the same reason.

### `length_squared()` as the normalization precondition proxy
The tests call `normalized()` and `normalize()` only on vectors whose `length_squared()` is well above `EPSILON * EPSILON`, respecting the implementation's assert exactly. No zero vectors are normalized — that would abort the process and block subsequent tests.

### Cross-product sign convention
The sign of `cross(a, b)` encodes rotation direction:

| Call | Result | Meaning |
|---|---|---|
| `unit_x.cross(unit_y)` | `+1` | `y` is CCW from `x` ✓ |
| `unit_y.cross(unit_x)` | `-1` | `x` is CW from `y` ✓ |
| `v.cross(v)` | `0` | Parallel — no rotation ✓ |

### Round-trip identity for `*=` / `/=`
```cpp
r *= 4.0f;
r /= 4.0f;
// must equal original a
```
This catches any off-by-one in the reciprocal path — if `1.0f / 4.0f` accumulated error, the final values would drift from `a`.

### Left vs. right scalar multiply commutativity
```cpp
assert(k * v == v * k);   // global vs member operator
```
Ensures the global `operator*` is not accidentally routing through a different code path than the member one.
